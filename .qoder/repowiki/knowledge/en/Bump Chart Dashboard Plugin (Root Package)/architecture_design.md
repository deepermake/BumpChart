This root scope defines the npm package manifest, build pipeline, and demo entry for the `bump-chart-dashboard-plugin` library. `package.json` declares dual outputs: an ES module (`dist/bump-chart-plugin.js`) and a UMD bundle (`dist/bump-chart-plugin.umd.cjs`), with `react` and `react-dom` as peer dependencies so consumers link their own copies. `vite.config.ts` switches between library mode (entry `src/plugin/index.ts`, externalizes React, emits named exports) and demo mode (outputs to `dist-demo/`). `tsconfig.json` enforces strict TypeScript with `jsx: react-jsx`, targets ES2020, and references `tsconfig.node.json` for Node-side config; declarations are emitted via `vite-plugin-dts`. `index.html` is the Vite dev server entry point loading `/src/main.tsx` for interactive demos. The module itself contains no source code — it orchestrates how the `src/` tree is compiled into a distributable plugin.
